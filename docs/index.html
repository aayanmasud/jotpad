JotPad

A lightweight Linux writing app for plain text and Markdown, with a live preview and text-focused DOCX import/export.

View GitHub releases

Available on: Linux, including Arch Linux and CachyOS; usable with the Hyprland Wayland compositor.
Arch/CachyOS users can build from source using the instructions below. No Arch package is advertised here unless one is published on the Releases page.

Install on Debian or MX Linux

Open the Releases page and download a Linux .deb asset if one is published. In a terminal, change to the directory containing the downloaded package (usually Downloads), then install it:

cd ~/Downloads
sudo apt install ./jotpad_*.deb

Search your applications menu for JotPad, or start it in a terminal:

jotpad

If no .deb is attached to a release, build from source using the instructions below. A GitHub source-code ZIP is not an installable Debian package.

Arch Linux and CachyOS (including Hyprland)

Hyprland is a Wayland compositor, not a Linux distribution. JotPad is a Linux desktop app and can be built from source on Arch-based systems; the instructions below install build prerequisites and run the app directly. They do not install a system package or create an application-menu entry.

Install the required build tools and common graphics/windowing development libraries with pacman:

sudo pacman -Syu
sudo pacman -S --needed base-devel pkgconf gtk3 libx11 libxcursor libxrandr libxi mesa

Install Rust/Cargo if needed (for example, with Arch's rust and cargo packages), then clone and run JotPad:

sudo pacman -S --needed rust cargo
git clone https://github.com/aayanmasud/jotpad.git
cd jotpad
cargo build --release
./target/release/jotpad

On Hyprland, launch it from a terminal inside your Wayland session. If the file picker or display backend fails, install the relevant GTK/Wayland/XWayland runtime components for your system and share the terminal error for diagnosis. AppImage or native Arch package availability is not claimed unless a corresponding artifact appears on the Releases page.

Build and install from source (Debian-based Linux)

Install the system libraries needed to build the desktop app:

sudo apt update
sudo apt install build-essential pkg-config libgtk-3-dev libx11-dev libxcursor-dev libxrandr-dev libxi-dev libgl1-mesa-dev

Install Rust and Cargo using the official Rust instructions if they are not already installed. Then clone and build JotPad:

git clone https://github.com/aayanmasud/jotpad.git
cd jotpad
cargo build --release
./target/release/jotpad

To create and install a Debian package:

cargo install cargo-deb
cargo deb
sudo apt install ./target/debian/*.deb

If Cargo reports that cargo-deb is already installed, continue with cargo deb. If packaging reports a missing asset, verify the checkout contains assets/jotpad.desktop and assets/jotpad.svg.

Using JotPad

  • Create a document, open a text or Markdown file, edit it, and save it from the toolbar.
  • Use the formatting toolbar to add Markdown syntax for headings, bold, italic, lists, quotes, and code. Use Preview to view rendered Markdown.
  • Editor font-size and text-color controls affect the editor view; they do not add rich-text styling to Markdown files.
  • The start page provides create/open actions and can list recently opened or saved files in versions that include recent-file support.
  • Keyboard shortcuts: Ctrl+N for new, Ctrl+O for open, and Ctrl+S for save (use Command instead of Ctrl on macOS).

DOCX compatibility: JotPad handles DOCX primarily as text. It does not preserve Word page layout, tables, images, or rich formatting. DOCX export may contain plain text rather than the Markdown styling shown in Preview.

Update JotPad

Versions with the update checker can query GitHub for the latest published release and notify you if it is newer than the app version. The notification links to the release page; it does not download or install updates automatically. This requires an internet connection and a published GitHub Release.

To update a source checkout and rebuild:

cd ~/jotpad
git pull origin main
cargo build --release
cargo deb
sudo apt install ./target/debian/*.deb

If Git refuses to pull because of local edits, do not run git reset --hard unless you intend to discard them. Back up or commit your work first, or get help resolving the pull safely.

Completely uninstall

Remove the installed Debian package and then unused dependencies:

sudo apt purge jotpad
sudo apt autoremove --purge

Optionally remove JotPad's local recent-file history/settings:

rm -rf ~/.config/jotpad

This does not remove your documents or cloned source checkout. Remove that folder only if you no longer need it and have backed up local changes:

rm -rf ~/jotpad

Troubleshooting

  • App is not in the menu: confirm installation completed, try jotpad in a terminal, then sign out and back in if needed.
  • No package was found: cargo deb must finish successfully and create a file under target/debian/ before installation.
  • No update notice: a commit alone is not a release. Check the Releases page and confirm the published version is newer than the installed app.
  • Build or installation fails: copy the complete terminal output and open an issue at GitHub Issues.
